FROZEN CONTRACT:
```python
# src/hippo/knowledge/public_errors.py
@dataclass(frozen=True)
class PublicFailure:
    code: str          # closed set below
    message: str       # bounded generic text, never exception text
    http_status: int

def public_failure(exc: BaseException) -> PublicFailure | None   # None = not an activation/retrieval failure; caller falls through to existing handling
```
Closed mapping exactly as the plan table: mixed/unverified/invalid dense evidence or stored profile mismatch/change → `retrieval_rebuild_required`, 409, "Rebuild compatible sources before retrieval"; model metadata/embed/chat unavailable or timeout (`OllamaError` family, connection and timeout errors from the model client) → `retrieval_unavailable`, 503, "Retrieval service is unavailable"; build actor/authorization/suppression changed (`AuthorizationChanged`) → the existing generic permission response codes (409/403 as the current handlers already do; return `None` and let the existing handler run, or return the existing code, but never a new message); invalid client input / unsupported type / size (`TooLarge`, `UnsupportedProvenanceFormat`, the closed input validators' `ValueError` subclasses) → `invalid_source`, 400 or 413, reusing the existing bounded validation text from closed validators only; unknown managed build/query exception (`BuildBusy`, `BuildCancelled`, `ProjectionError`, bare `ValueError` from `canonical_selected_generations`, anything else raised inside the managed paths) → `operation_failed`, 500, "Operation failed; inspect local logs by operation ID". The function is pure: no logging, no I/O, no `str(exc)` in any returned field. Tests inject exception strings containing a fake secret, an absolute path, source text and a model body and assert none appears in any `PublicFailure` field.
