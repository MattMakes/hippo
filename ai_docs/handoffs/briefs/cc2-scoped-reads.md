REQUIRED BEHAVIOR (amended 2026-09-12 by the design review, `ai_docs/reports/2026-09-12-code-capture-plan-review.md` M3, M4, M5; read those three sections first):
1. Two scoping keys, not one. `native_write` and `native_mutation` scope by `ids=` (`native_write` must still find a PRIOR row before the generation is known, and `native_mutation` must still discover which argument strings are native IDs and still raise `Native relationship crosses generations` for an edge whose endpoints belong to two generations, and still admit an edge to an untagged legacy row): collect the candidate IDs from the rows or the call's args/kwargs and do one `_native_rows(kind, ids=...)` lookup per kind. `_inventory` and `generation_checksums` scope by `generation_id=`. Parameterised `_native_rows(kind, *, ids=None, generation_id=None)`, `_native_relationships(*, generation_id=None, ids=None)` and `_knowledge_rows(kind, *, generation_id=None)` on every backend, each one bounded query per call. 2. Index-backed on the backends that support one: add `CREATE INDEX ... ON (n.generation_id)` for `Symbol`, `DataObject`, `Commit` and `Passage` to `store/base.py`'s schema statements (and `store/migrations.py` with a guarded, journaled step if a schema-version bump is the only way to add them to existing stores; say which); decide and document the Ladybug story explicitly (Ladybug creates no secondary indexes today; either add support or state that scoped reads are bounded there by the query only). CD1 evidence must show the schema statement, not only a query counter.
3. Test: sealing a generation at the symbol ceiling (use a synthetic 50,000-row fixture on Fake with a CPU-time or operation-count bound) is linear in the generation.
4. A query-count bound test: writing N rows in batches of B performs O(N/B) scoped reads and never a whole-table read (instrument the Fake store; on Ladybug count statements through the driver hook or a minimal counter).
5. Unscoped reads remain available for the legacy lane and collection where they are correct today; nothing changes for legacy sources.
