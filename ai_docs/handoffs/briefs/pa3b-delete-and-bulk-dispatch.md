FROZEN CONTRACT:
```python
delete_source(ctx, source_id, *, build_actor: BuildActor | None = None, operation_id: str | None = None) -> None
reindex_all(ctx, *, build_actor: BuildActor | None = None) -> int
```
Delete dispatch: managed + actor → `tombstone_managed_source` (generate a bounded operation ID when none is supplied; the HTTP layer keeps returning `{"deleted": source_id}` after commit and a subsequent lookup returns the same 404 as any unavailable source); managed WITHOUT actor → raise before any legacy delete hook, file removal, or generation mutation, never fall back; unmanaged → existing legacy path unchanged; tombstoned → the same generic not-found as an inaccessible source, no mutation.

`reindex_all` protocol, in order: (1) existing `edit_graph` and no-index-job preconditions; (2) snapshot current Source rows; (3) classify every source with `managed_eligibility`; skip tombstones; (4) for every managed refresh and eligible conversion, capture `BuildAuthority` (via the Task 1/coordinator primitives, not a new policy path) with the supplied actor; if ANY managed preflight fails, clear nothing, start nothing, and return 0 with no hidden per-source breakdown; (5) run `_prepare_reindex` for the legacy lane only, completing all legacy clears before starting any job; (6) submit each lane with its immutable actor and a fresh operation ID; (7) every worker rechecks classification and authority at execution, and a race (conversion, suppression, ACL change, actor change) fails that lane safely without legacy fallback; one lane's asynchronous failure never clears another source, changes another active pointer, or makes another G1 unavailable. Without an actor, managed sources in the inventory make the bulk refuse before any clear (they cannot be refreshed and must not be cleared).
